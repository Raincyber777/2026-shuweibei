## 配色约定（跨图一致）

- Q1：蓝 = 可行域、白 = 遮挡/不可行、灰 = 建筑；黑虚线圆 = r_min 禁区；
- 甘特（图 4-7/4-11a）：travel 浅蓝 #CBDCEF、slew 橙 #F5C68B、wait 灰 #E6E6E6、observe 绿 #3E9B6C、reset 粉 #F2B0A6；
- 折线图：蓝 = 主曲线/解析、红 = 阈值/keep-original、绿 = reschedule/0.95 线、橙/purple = 参数变体；
- 红五角星 = 目标水平投影；黑五边形 = 选定站点。

## 复现方式

```
cd B题/论文图表
python -I make_fig_4_1_to_4_7.py     # 图 4-1..4-7（含 T1/T2 栅格重算，约 1-2 min）
python -I make_fig_4_8_to_4_11.py    # 图 4-8..4-11（约 30 s）
```
依赖：numpy、matplotlib、SciencePlots（pip install SciencePlots）、statistics（标准库）。
